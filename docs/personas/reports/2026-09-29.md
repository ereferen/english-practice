## 気づき詳細（触って確認したこと）

- **話題の入口が無い**: 英会話の初期画面は「英語でメッセージを送って会話を始めましょう！ / 例: "Hi! How are you?", "What did you do today?"」の 2 例文のみ。会話画面の操作は クリア / 戻る / 送信 / 読み上げ / この会話から学ぶ だけで、話題・相手役・レベルを選ぶ UI が無い。設定画面の項目も 1日の目標語数 / 音声フィードバック / バックアップ・復元 / Self-Improve / AI 設定 の 5 つだけで、会話の話題に関する設定は無い（全画面テキストを確認）。10 往復は自分でネタを出し続けて回した。
- **会話ログは直近1セッションのみ**: リロード後に英会話を開くと「💾 前回の会話を復元しました（直近1セッション分をこの端末に保存しています）」が出て 20 バブル（10 往復）が復元された。これは #138 の修正が効いている。ただし `src/storage/types.ts:154` に「保持するのは直近1セッションのみ（無制限に貯めない）」とあり、保存先は 1 スロット。新しい会話を始めると前のログは残らない作りになっている。
- **「次の語」の注意書きが 0.5 秒**: めくる前に `次の語` を押すと「⚠ 先にカードをめくって意味を確認しましょう（クリック / Space）」が出るが、DOM を 0.1 秒刻みで監視したところ **0.02s〜0.50s は表示 / 0.62s で GONE**（`FlashScreen.tsx:117` の `setTimeout(..., 500)`）。文言は 32 文字あり、0.5 秒では読み切れない。ボタンの computed style は `disabled:false / opacity:1 / pointer-events:auto / cursor:pointer` で、見た目は完全に有効。実際に 0.7 秒あけて確認すると「押しても何も起きない」状態に見えた。フリップ必須の仕様自体は #124 の意図どおりで正しい。
- **削除確認だけブラウザ標準**: 会話の `クリア` を押すと `window.confirm("会話履歴を削除しますか？")`、設定の `すべてのデータを削除` を押すと `window.confirm("すべてのデータを削除しますか？この操作は元に戻せません。")` が呼ばれる（confirm をフックして検証、どちらもモーダル DOM は生成されない）。一方でキーボードショートカット一覧は `modal-overlay` + `card _modal_` のスタイル付きモーダルで、アプリ内にモーダル基盤がある。
- **抽出デッキの並びとレベル**: `会話から学ぶ` で 3 件追加すると「✓ 3 件を「会話から抽出 (2026-09-29)」に追加しました。」→「この 3 語を今すぐ学習」が出る（#141 の修正を確認、導線は良好）。ただしデッキ一覧での並びは 学術・論説語彙(advanced) / 職場・日常中級語彙(intermediate) / 中学基本語彙(beginner) / **会話から抽出 (2026-09-29)(intermediate)** の順で最下段。レベルは `conversationExtract.ts:354` の `level: opts.level ?? ## ここ良かった

- **会話 → 抽出 → デッキ追加 → 即学習が一気通貫**。3 件が「語彙 / 表現 / 文法訂正」に分類され、文法訂正には `✓ I agree with you.` と「agree は動詞なので be 動詞は付けない。」の解説つき。「I'm agree」と書いた自分のミスがそのまま教材になって、弱点（語彙・アドリブ）に直撃。追加後すぐ「この 3 語を今すぐ学習」が出るのが前回からの改善点で、これは本当に使いたい。
- **ホームの数字が全部つじつまが合う**。クイズ 2/4 → 目標達成率 40%（4/10 回答）→ 目標を 20 に変えたら即 20%（4/20）に追従。連続学習日 1 日も、デッキの学習率 33%（5/15 語）も、セッション数・平均正答率 50% も全部一致していて数字が信用できる。

- **キーボードだけで朝の復習が完走できる**（Space めくり / ← 前へ / n・→ 次の語 / 1-4 で回答 / Enter 確定 / s 読み上げ / h ホーム / ? 一覧）。所要 49 秒。`h` でどの画面からでもホームに戻れるのも効いている。

## 気づき詳細（触って確認したこと）

- **バックアップにAPIキーが平文**（#180）: 設定のAPIキー欄にダミー文字列を入れて（自動保存）→「バックアップをダウンロード」→ `english-practice-backup-2026-10-11.json`（2268 bytes）を開くと `settings[0].llmApiKey` に入力値がそのまま平文で入っていた。`"llmApiKey": "sk-…"` を確認。バックアップを共有/クラウド保存する前提だと漏洩リスク。
- **自分のデッキが追加後に管理できない**（#181）: 「単語を追加」で語を入れると「自分のデッキ / 手動追加 (2026-10-11)」が自動生成される。デッキ詳細のボタンは「戻る / 学習・クイズ / ✨LLMで補充問題を生成 / 🎯苦手語集中トレーニング」のみで、**名前変更・デッキ削除・語の一覧/編集/削除の導線が 0**。デッキ一覧にも各デッキの操作メニュー無し。サンプル3デッキも個別非表示/削除不可（消すのは「すべてのデータを削除」だけ）。前回 #178 で入れた「追加の入口」は効いているが、追加後の手入れが無い。
- **クイズ解答後に例文/ノートが出ない**（#182）: フラッシュカード裏面は 発音+意味+品詞+例文+ノート まで出るのに、クイズは解答後も「4択 + ○正解/×不正解 + 次へ」のみ。実測（friendly）: `friendly / ✗ 高価な / 静かな / 疲れた / ✓ 親しみやすい / × 不正解 / 次へ`。例文・発音・ノートはどこにも出ない（セッション完了画面の「誤答した語」も語＋意味＋🔇 のみ）。
- **インポート失敗が英語の生エラー**（#183）: テキストエリアに `{not valid json` を入れて「インポート」→ `インポート失敗: Expected property name or '}' in JSON at position 1 (line 1 column 2)`。日本語の言い換え無し。正常系（自分のバックアップを貼ってインポート）は通ることも確認済み。
- **会話UIは未設定時フルロック**（既報・重複のため今回は起票せず）: 話題チップ4つ + 送信 + textarea がすべて `disabled=true`。前回 #175/#173 で扱い済みのため新規起票なし。会話の往復そのものはエンドポイント未設定で未実施（評価対象外）。

## ここ良かった

- **フラッシュカードのキーボード操作が全部効く**。Space でめくる / n・→ で次の語 / ← で前の語 / s で音声。実操作で全キーが期待通りに動いた（CDP の本物キーイベントで確認）。クリック無しで5枚サクサクめくれて、朝の5分に向いてる。
- **ホームの「今日の復習」カードから直接復習セッションに入れる**。`復習セッション (1/4)` が即始まり、デッキを選び直さない。#82 の修正が効いている。
- **クイズが3形式混在**。EN→JA / JA→EN / 穴埋め（The ___ is nice today.）が出る。アドリブが苦手な自分には穴埋めが実戦っぽくて良い。
- **失敗系のガードが日本語で丁寧**。「苦手語集中トレーニング」→「まだ苦手語はありません（誤答2回以上）」、弱点レポート→「直近30日で10回必要です（現在 4 回）」、接続テスト→「エンドポイントに到達できません（URLミス or サーバーダウン）」。数字付きで「あと何回やればいい」が分かる。
- **バックアップのファイル名が素直**。`english-practice-backup-2026-10-11.json` で日付が入っていて、フォルダに複数あっても見分けやすい。

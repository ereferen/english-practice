## 気づき詳細（触って確認したこと）

- **抽出直後のCTAで詰む**（#186）: 「✓ 3 件を「会話から抽出 (2026-10-13)」に追加しました。この 3 語を今すぐ学習」→ 押すと `クイズがありません / クイズには4語以上必要です。このレッスンは現在3語です。` に直行。押せるのは `✨ デッキ画面で補充問題を生成する` / `戻る` だけ。一方、同じ3語レッスンでもデッキ画面の「学習・クイズ」からは `フラッシュカード (1/3)` が普通に開く（クイズだけが4語ゲートで封印）。1語デッキで同じ画面を再現しスクショ取得済み。
- **抽出パネルに品詞・読みが出ない**（#187）: パネルのDOMは `checkbox + span(語彙/表現) + span(語) + span(意味)` と `p(例文)` のみ。抽出プロンプトは `partOfSpeech` を要求しているのに表示されていない。フラッシュカード裏面は `発音(カタカナ) / 意味 / 品詞 / 例文 / ノート` まで出る。
- **LLM差し替え時の抽出エラーが生のスキーマ文字列**（#188）: キー名が違うモデルに替えると `⚠ 抽出結果のスキーマ検証に失敗しました: items.0.term: Required / items.1.term: Required / items.2.term: Required`（別パターンで `items: Required`）。送信失敗カードは日本語＋「詳しく（技術情報）」の折りたたみで丁寧なのに、抽出だけ流儀が違う。
- **学習率がカード閲覧だけで100%**（#189）: 手動追加デッキで `学習率 0%` → カード3枚をめくるだけ（クイズ0問・クイズは4語未満で不可）→ `学習率 100%`。定義の説明が画面上に見当たらない。
- **良くなっていた点（前回指摘の反映確認）**: クイズ解答後に例文＋紛らわしい語の注記が出る（#182: `library は「図書館」。water (水) と綴りが似ていて混同しやすい。`）／抽出結果に「この N 語を今すぐ学習」の導線がある（#141）／削除確認がアプリ内モーダル（#150）／バックアップにAPIキー非同梱の注記（#180）／OpenCode Go がヘッダ必須で接続不可である旨の注記（#174）／会話ログが直近3セッション保存され「💾 前回の会話を復元しました」（#148）／未設定時の話題チップが正しく `disabled`（#173・#175）／送信後のフォーカス保持（#157）／自分のデッキの名前変更・語の編集・削除（#181）。

## ここ良かった

- **会話（10往復）が普通に気持ちよく回る**。話題チップで相手から話を振ってくれる／Enterで送信／送信後も入力欄にフォーカスが残る／ストリーミングで1語ずつ出る／各メッセージに🔇読み上げが付く。自分の発言は右寄せ・相手は左寄せで、パッと見で区別できる。
- **失敗時の日本語が具体的**。「送信できませんでした（接続先 1 件で失敗）。設定画面でエンドポイントを確認してください。」＋「詳しく（技術情報）」の折りたたみは、原因の切り分けができて助かる。
- **会話・設定がリロードしても残る**（別途リロードテストで検証: `answers=4 / sessions=1 / review=4 / settings=1` が保持、ホームの数字も復元）。
- **接続テストが 0.1s で返り、成功時は設定画面に「✓ 接続確認済み（このエンドポイントで接続テスト成功）」** と出る。どのエンドポイントで成功したのかが分かる。
- **クイズの不正解時に、正解＋例文＋「〜と綴りが似ていて混同しやすい」の一言**まで出る。語彙が弱点の自分には効く。
- **設定が実測値で語る**。セッション時間が実測（36秒 / 6秒）、平均正答率に「参考値（サンプル少なめ）」、抽出した語デッキは「自分のデッキ」として分けて表示。数字が浮かない作りになっていた。
- **キーボードショートカット一覧（?）が会話まで対応**。`Enter メッセージ送信 / Shift+Enter 改行 / Esc 入力をクリア` が載っていて、初見でも迷わない。

## ここ良かった（続けるモチベ）

- **会話がちゃんと動く**。モック相手でも、話題チップ → 相手から振ってくる → 自分の英文 → 返事、までテンポよく回った。返事の英単語がそのまま押せるボタンになっていて（`playing` / `lately` / `queue` …）、語彙が弱点の身としてはここが一番ありがたい。
- **ヒントの失敗が正直**。モックがヒント形式（短い英文3つの配列）を返さなかったとき、`ヒントを作れませんでした。LLMの返答がヒントの形式になっていませんでした。もう一度押すか、話題を変えてみてください。` と理由と逃げ道が出た。「黙って死ぬ」を卒業している。
- **接続テストの成功が会話を解錠する**。`✅ 接続OK（model: mock-aki、往復 0.1s）` → 会話画面の全ロックが外れ、`💾 前回の会話を復元しました（話題: 🎮 ゲーム）` まで出た。設定→会話の導線が繋がっている。
- **キーボード操作が実際に効く**。Space でめくる、`1`〜`4` で解答、どちらも CDP の実キーイベントで確認。案内文と挙動が一致している。
- **スマホ幅で崩れない**。390×844 で ホーム / デッキ一覧 / デッキ詳細 / ダッシュボード / 会話 / 設定 を見て、横スクロール 0、32px 未満のタップ領域も無し。
- **デッキの「隠す」が戻せる**。隠すと `非表示のデッキ（1）` に落ちて `表示に戻す` が出る。片道切符じゃないのは安心。

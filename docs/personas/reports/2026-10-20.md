## 気づき詳細（触って確認したこと）

- **抽出カードの和訳欄が英語**（#201）: `steep learning curve` のカード裏が `読み / 意味 / 例文: That game has a steep learning curve at the beginning. / the latency is lower`。最後の行は和訳用のクラス（`_exampleJa_...`）に入っているのに中身は会話の原文（英語）。`small talk` も同じで和訳位置に `small talk before a meeting`。コードは `conversationExtract.ts` で `examples[0].ja = item.sourceText`。
- **クイズの問題数が語数と合わない**（#202）: 5 語のレッスンで `クイズ (1/6)`、出題は weather → travel → library → travel（意味選択）→ breakfast → friendly。誤答 3 語のやり直しも `クイズ (1/4)` で travel が 2 回。`answers` にも 1 セッション内で travel が 2 件。`loader.ts` の `generateQuizzesForLesson` が未カバー 1 語につき `choose-meaning` と `fill-blank` の 2 問を足しているため（明示 4 問 ＋ travel 用 2 問 = 6 問）。
- **小型デッキの「クイズへ」がデッドボタン**（#203）: 手動追加（1 語）/ 会話から抽出（3 語）で「クイズへ」を押しても遷移なし・トーストなし。押すとカードが表に戻り、`⚠ 先にカードをめくって…` が復活する。警告は `デッキ画面の「✨ LLMで補充問題を生成」` へ誘導するが、この画面にそのボタンは無く、戻る → デッキ → ✨ の 3 手が必要。
- **復習 5/5 正解でも「今日の復習 3 語」**（#204）: 完了画面は `復習セッション完了 / 100% / 5 語中 5 語正解` ＋ `戻る` `進捗ダッシュボード` のみ（学習完了にある「ホームへ」が無い）。`review` を見ると正解 3 語が `level 1 / dueAt 当日`（`intervalDays: [0,0,1,4]` の level 1 = 0 日）。
- **平均正答率 58% の根拠が画面に無い**（#205）: 回答は 15 件中 9 件正解（60%）だが表示は 58%。`Dashboard.tsx` はセッション正答率の単純平均（(50+25+100)/3 = 58.3）。問題数で重み付けしていない。

## 気づき詳細（触って確認したこと）

- **再送でログが二重化する**（#166）: LLM を落として送信 → 「送信できませんでした（接続先 1 件で失敗）…」のエラーカードが出る → LLM を復旧して「再送」を押すと、`user` バブルの同じ文言が 2 つ並び、間のエラーカードも残ったまま。再送前の並びが `user → npc(エラー)`、再送後が `user → npc(エラー) → user → npc(返事)`。失敗した 1 件を置き換えるのではなく追記している。
- **話題チップの無反応**（#167）: 未検証状態（入力欄は `disabled=true` / placeholder「⚠ 先に設定（APIエンドポイント）が必要です」）でチップを押すと、チップは `disabled=false` のまま無反応。押下前後でバブル数 34→34・区切り行 2→2 で変化なし、`aria-live` に新規通知なし。ただし「話題: 💼 仕事の雑談」の見出しだけは切り替わる（＝押した側は選べたと誤解する）。
- **品詞バッジが other**（#168）: 抽出デッキの全カードで裏面のバッジが `other`。サンプルデッキは `noun`。`src/domain/conversationExtract.ts` の `guessPartOfSpeech()` が意味・読み・解説に「名詞／動詞」等の語を含まない場合に `"other"` を返し、抽出プロンプトは品詞を要求していないため実質すべて other に落ちる。`FlashScreen.tsx` がその値をそのままバッジ描画している。
- **Shift+Enter 改行が存在しない**（#169）: ショートカット一覧に「英会話 → Shift+Enter 改行」とあるが、入力欄は `<input class="_chatInput_…">`（textarea ではない）。「line one」入力後に Shift+Enter を押しても改行されず、送信もされず、値も変わらない。Enter 単体の送信は動く。
- **送信中は二重送信できない**: 応答を 3 秒遅らせて送信直後に Enter を再投入しても 2 通目は送られなかった（送信ボタンも送信中は別表示になる）。ガードは効いている。
- **未確定として見送った点**: 会話の「読み上げ」はヘッドレス Chrome に TTS ボイスが無いため `🔇` 表示で、実機での挙動は確認できず（#83 の対応どおりの表示なので起票せず）。抽出デッキのレベル既定は「中級」で、抽出時に明示選択しないまま追加しても中級になった（仕様と読めるので起票せず）。

## 気づき詳細（触って確認したこと）

- **手動追加の語は読みも品詞も持てない**（#191）: 「単語を追加」の書式は `語, 意味, 例文(任意)` ＋ レベル選択のみ。`commute, 通勤する, I commute by train.` を投入 → カード裏が `— / 通勤する / （品詞バッジなし） / I commute by train.`。サンプル語の裏面（`ブレックファスト / 朝食 / 名詞 / …`）と並べると、自分で足した語だけ読みが `—` で品詞が消える。デッキ詳細の「登録した単語」一覧も `語 / 意味` だけ。
- **文法訂正カードの見せ方**（#192）: 抽出パネルでは `文法訂正 / I very like this game. / 説明 / ✓ I really like this game. / ノート` と丁寧（#187 の修正が効いている）のに、カードに落ちると表＝間違えた文、裏＝ `— / 説明 / I really like this game. / I very like this game.`＋ノート。表を見て「どこが直るか」を当てる形になり、読み欄は `—`。
- **クイズが出題語を網羅していない**（#193）: 中学基本語彙「日常生活」= 5 語 / クイズ **4問**（travel 未出題）、職場・日常中級語彙「職場で」= 5 語 / クイズ **3問**（schedule・careful 未出題）。レッスン表示は `5 語` のみで、出題数は始めるまで分からない。クイズ配列が用意されているレッスンでは自動生成が走らないため、用意数がそのまま出題数になっている。
- **誤答語のやり直し導線が無い**（#194）: セッション完了は `33% / 正解 1 / 3 問 / 誤答した語: colleague（同僚）🔇 / deadline（締切）🔇` ＋ `ホームへ / 進捗を見る / デッキへ`。`デッキへ` → `学習・クイズ` は `フラッシュカード (1/5)` からで、`クイズへ` は最終カードにしか出ないため、5枚めくり直しが必須。
- **デッキ一覧に進捗が無い**（#195）: 一覧の各行は `レベル · N レッスン` ＋ 非表示ボタンのみ（例: `中学基本語彙 (サンプル) / beginner · 3 レッスン`）。同じデッキを開くと `学習率 33%` と `このデッキの復習（4語）` が出る。ホームの「今日の復習」には `最多: 中学基本語彙 (サンプル) 4語` と出るので、情報はあるのに一覧では隠れている。

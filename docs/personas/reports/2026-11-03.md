## メモ（運用）

- モックは `/home/tenki/.hermes/cache/scratch/mock_llm.py`（`0.0.0.0:8787`、CORS と `Access-Control-Allow-Private-Network` 付き）。`127.0.0.1` だけに bind するとデプロイ先オリジンから届かないので 0.0.0.0 で立てる。
- 設定画面は同一ドキュメント内の hash 遷移では再読込されず、IndexedDB を直接いじっても画面の state は古いまま。反映確認は `location.reload()` が必要。
- 入力欄への値投入は、ネイティブ setter + `input` イベントだと React の state が更新されないことがある。CDP の実キー入力（`Input.dispatchKeyEvent` の `char`）で入れると通った。

## 気づき詳細（触って確認したこと）

- **設定から戻ると会話に戻れない**（#170）: 英会話 →「設定を開く」（バナー内・本文の2箇所どちらでも）→ 設定画面 →「戻る」を押すとホームが開く。会話を再開するには「英会話」を押し直す（3タップ）。会話の入力欄に打ちかけの内容があってもそのまま捨てられる。
- **警告リボンが学習中も常駐**（#171）: 実測で `position: sticky; top: 0; z-index: 40;` 高さ 47px。フラッシュカード (1/5)・クイズ (1/4) のような LLM と無関係な画面でも上に張り付いたまま消えない。設定済み（接続確認済み）になると消えることは確認した。
- **未設定時の話題チップが完全無反応**（#173）: 入力欄は `disabled=true` / placeholder「⚠ 先に設定（APIエンドポイント）が必要です」、送信も disabled。一方で 🎮ゲーム / ✈️旅行 / 💼仕事の雑談 / 🙋自己紹介 のチップは `disabled=false` のまま。押しても本文が一切変化しない（前後とも 504 文字で差分ゼロ）、エラーもトーストも出ない。説明文は「選ぶと相手から話を振ります」。設定済みにすると同じチップが正常に会話を開始する（「— 話題「🎮 ゲーム」で会話を開始 —」）。
- **エンドポイント例が罠**（#174）: フォールバック側エンドポイントの placeholder が `https://opencode.ai/zen/go/v1`。設定できるのは「API エンドポイント / モデル名 / API キー」の3項目のみで、カスタムヘッダ欄が無い。OpenCode Go は `x-opencode-session` ヘッダ必須のため、例のまま入力しても 400（MissingSessionID）で弾かれるはず。
- **会話10往復は健全**: 送信ごとにバブルが正しく増え（開始1 + 10往復 = 11 の相手発言）、重複や残留は無し。話題スイッチは「— 話題を「✈️ 旅行」に切り替え —」の区切り行として残り、自分の発言としては混入しない（#159 の修正が効いている）。抽出は「2 件の学習項目を見つけました」＋チェックボックス＋レベル選択＋却下まで動いた。

## ここ良かった

- **クイズの問題形式が3種類混ざるのがいい**。同じ 4 問の中で「The ___ is nice today.」（穴埋め）、`friendly`（EN→JA）、`図書館`（JA→EN）が出て、訳語当てだけの単調さが無い。アドリブが苦手な身としては穴埋めが実戦っぽくて効く。
- **フラッシュカードの「ノート」欄が刺さる**。travel の裏面に「名詞で短く『1回の旅行』なら a trip の方が自然な場面が多い。」が出た。ただの訳語でなく使い分けまで書いてあるのは語彙が弱い自覚のある自分に一番効く。
- **セッション完了画面が素直で気持ちいい**。「100% / 正解 4 / 4 問 / セッション時間 15秒 / ホームへ・進捗を見る・デッキへ」と数字が浮かずに並ぶ。15秒という実測まで出るので「今日は早かった」が分かる。
- **会話の話題スイッチが区切り行として残る**。押した側の選択が自分の発言としてログに混ざらないので、後から読み返しても誰が何を言ったか崩れない。
- **弱点レポートのガードが正直**。「分析には直近30日で少なくとも10回の回答が必要です（現在 0 回）。」と必要数を明示して止まる。データが無いのに失敗画面を出さない（#116 の修正が効いている）。
- **ショートカット一覧が画面ごとに整理されている**。フラッシュカード / クイズ / 英会話 / 全画面共通で分かれ、「入力フィールドにフォーカス中はショートカットは無効になります。」まで書いてある。改行は Shift+Enter と明記され、#169 の修正が反映されていた。
- **接続成功時の表示が具体的**。「✓ 接続確認済み（このエンドポイントで接続テスト成功）」＋「✅ 接続OK（model: mock、往復 0.1s）」で、どのモデルに何秒で届いたかまで出る。
